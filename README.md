## English

### Description

`tmdbToLetterboxd` is a console application that reads a TMDb (TheMovieDB) list and exports the found movies to a CSV file (`watched.csv`).
For each movie, the tool exports the following fields: Date (`release_date`), Name (`title`), and Year (extracted from `release_date`).

### Key Features

* **Automatic Fallback:** If `watched.csv` is locked or in use, the app automatically creates a timestamped fallback file (e.g., `watched_yyyyMMddHHmmss.csv`).


* **Flexible Input:** Run with command-line arguments or use the interactive mode, which hides your API key while typing.


* **Robust Error Handling:** The app verifies your TMDb API key authentication before proceeding and gracefully skips pages if JSON parsing fails.


* **CSV Formatting:** Fields are properly escaped for commas and quotes to ensure data integrity.



### Requirements

* .NET 8 SDK. ([Download .NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0))


* An active Internet connection.


* A valid TMDb API key.



### Download Pre-built Executable

If you prefer not to build the source code yourself, you can download the ready-to-use executable from the **Releases** page.
If you run the downloaded executable by just double-clicking it (without providing command-line arguments), it will interactively prompt you to enter the API Key and the Link/List ID, masking your input for security while you type.

### How to get a TMDb API Key

If you don't have a TMDb API Key, you can generate one for free by following these steps:

1. Create an account or log in to [TheMovieDB (TMDb)](https://www.themoviedb.org/).
2. Click on your profile picture in the top right corner and select **Settings**.
3. In the left sidebar, click on the **API** section.
4. Click on the link to request a new API Key and select the **Developer** option.
5. Fill out the required form with basic details about how you plan to use the API (e.g., "Personal script to export movies to Letterboxd") and accept the terms of use.
6. Once submitted, your **API Key (v3 auth)** will be generated instantly. Copy this key to use in the application.

### How to Import to Letterboxd

Once you have generated your `watched.csv` file, follow these steps to import it into Letterboxd:

1. Go to [Letterboxd.com](https://letterboxd.com/) and log in to your account.
2. In the top navigation menu, click on **Films** and select **Import**.
3. Click the **Select a file** button (or drag and drop) to upload the `watched.csv` file generated by this application.
4. Letterboxd will automatically map the columns (`Date`, `Name`, `Year`). Verify that the preview looks correct.
5. Click **Import films** to add them to your watched list/diary.

### Build and Run (From Source)

* **Publish the app:**
```bash
dotnet publish -c Release
```


* **Run in development:**
```bash
dotnet run -- <LIST_ID> <API_KEY>
```



### Usage

* **With command-line arguments (Recommended):**
`dotnet run -- LIST_ID API_KEY` (or pass them directly to the executable: `tmdbToLetterboxd.exe LIST_ID API_KEY`)
Note: `LIST_ID` can be the exact TMDb list ID or the last segment of the list URL.


* **Without arguments:**
Simply launch the app (or double-click the executable) and it will prompt you for the API Key and Link/List ID using hidden inputs.

## Italiano

### Descrizione

`tmdbToLetterboxd` è un'applicazione console che legge una lista da TheMovieDB (TMDb) e scrive i film trovati all'interno di un file CSV (`watched.csv`).
Per ogni film vengono esportati i seguenti campi: Date (`release_date`), Name (`title`) e Year (anno estratto da `release_date`).

### Funzionalità Principali

* **Gestione File Bloccati:** Se il file `watched.csv` principale è bloccato (ad es. aperto in un altro programma), viene utilizzato un file alternativo con timestamp (es. `watched_yyyyMMddHHmmss.csv`).


* **Input Flessibile:** Supporta l'avvio con argomenti da riga di comando o una modalità interattiva con input mascherato per proteggere l'API Key durante la digitazione.


* **Gestione degli Errori:** L'autenticazione viene verificata prima di procedere; eventuali errori di parsing JSON di singole pagine vengono ignorati con un avviso, permettendo all'elaborazione di continuare.


* **Formattazione CSV Sicura:** I campi CSV vengono automaticamente "escapati" per gestire correttamente virgole e virgolette nei titoli.



### Requisiti

* .NET 8 SDK. ([Scarica .NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)) - *Necessario solo se compili dai sorgenti*.


* Connessione Internet attiva.


* API Key TMDb valida.



### Scaricare l'eseguibile precompilato

Se preferisci non compilare il codice sorgente, puoi scaricare l'eseguibile pronto all'uso dalla pagina delle **Release**.
Se avvii l'eseguibile scaricato con un semplice doppio clic (senza passare argomenti da riga di comando), il programma ti chiederà in modo interattivo di inserire l'API Key e il Link/ID della lista, nascondendo l'input per sicurezza durante la digitazione.

### Come ottenere l'API Key TMDb

Se non possiedi un'API Key TMDb, puoi generarne una gratuitamente seguendo questi passaggi:

1. Crea un account o accedi su [TheMovieDB (TMDb)](https://www.themoviedb.org/).
2. Clicca sull'icona del tuo profilo in alto a destra e seleziona **Impostazioni** (Settings).
3. Nel menu laterale a sinistra, clicca sulla sezione **API**.
4. Clicca sul link per richiedere una nuova API Key e scegli l'opzione **Developer** (Sviluppatore).
5. Compila il modulo con i dettagli richiesti (es. puoi scrivere "Script personale per esportare film su Letterboxd") e accetta i termini di utilizzo.
6. Una volta inviato il modulo, la tua **API Key (v3 auth)** verrà generata immediatamente. Copiala e utilizzala per avviare l'applicazione.

### Come importare su Letterboxd

Una volta generato il file `watched.csv`, segui questi passaggi per importarlo su Letterboxd:

1. Vai su [Letterboxd.com](https://letterboxd.com/) e accedi al tuo account.
2. Nel menu di navigazione in alto, clicca su **Films** e seleziona **Import**.
3. Clicca sul pulsante **Select a file** (o trascina e rilascia la finestra) per caricare il file `watched.csv` creato da questa applicazione.
4. Letterboxd mapperà automaticamente le colonne (`Date`, `Name`, `Year`). Verifica semplicemente che l'anteprima dei dati sia corretta.
5. Clicca su **Import films** per aggiungere la lista al tuo profilo.

### Build e Esecuzione (Dai Sorgenti)

* **Per pubblicare:**
```bash
dotnet publish -c Release
```


* **In fase di sviluppo:**
```bash

```



### Utilizzo

* **Con argomenti da riga di comando (Consigliato):**
`dotnet run -- LIST_ID API_KEY` (oppure passali direttamente all'eseguibile: `tmdbToLetterboxd.exe LIST_ID API_KEY`)
Nota: `LIST_ID` può essere l'ID della lista TMDb oppure l'ultima parte dell'URL della lista.


* **Senza argomenti:**
L'applicazione (o l'eseguibile) richiederà l'API Key e il link/ID della lista mascherando la digitazione.
